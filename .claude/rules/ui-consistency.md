# UI consistency rule

For any frontend UI work in this repository, read and follow [`docs/ui-guidelines.md`](../../docs/ui-guidelines.md). Reuse its shared page shell, design tokens, type scale, spacing, controls, form and table patterns, status treatments, and accessibility rules on every page.

Also read [`docs/specs/mvp-expense-tracker.md`](../../docs/specs/mvp-expense-tracker.md) when changing the Expense MVP. Keep its scope small. Do not add features, new visual patterns, dependencies, or screens unless the user requests them. When an explicit product requirement changes a shared UI rule, update the guideline so future pages stay consistent.
